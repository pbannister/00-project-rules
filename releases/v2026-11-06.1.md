# Release v2026-11-06.1 — evidence

Impact: breaking

## What changed

- `prompts/capabilities/` splits into `capabilities/artifacts/` (`01`–`05`) and
  `capabilities/execution/` (`06`–`09`), the split `documents/object-index.md`
  proposed.
- Every path reference updates: `MANIFEST`, `01-contract.md` section 2,
  `02-workflow.md` section 1, `03-conventions.md` Applicability and section 6.1,
  `prompts/README.md`, `evals/06-credential-boundary.md`, and
  `tests/09-prompt-contract.sh`.

## Why

The object model groups the capabilities into artifacts-and-pipeline and execution;
the flat directory mixed the two. The content axis argued for exactly one directory
change, and this release makes it.

## Machine-checkable evidence

- `make test` passes, including `tests/09-prompt-contract.sh` (registry and
  applicability) and `tools/tests/04-skeleton-integration.sh` (vendoring
  end-to-end).

## Behavioral evidence

Not run; no behavioral case changed.

## Adopters

- `00-project-skeleton` and every project that pins this version must re-vendor.
- A task that referenced an old capability path must update it.
