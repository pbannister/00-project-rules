# Release v2026-10-22.6 — evidence

Impact: wording

No instruction an agent follows changed.

## What changed

`tests/10-prompt-validator.sh` builds each fixture from `git ls-files` instead of
copying the working tree. The validator only ever reads tracked files, so the
untracked ones were pure cost.

## Why

Adopting the rules into `09-language-elseon` produced a green suite that took
about ten minutes. The project is not slow; the corpus was.

`reset()` copied the entire working tree once per case, and the corpus has 54
cases. That project's tree is 3.9 GB because `sources/` holds ignored research
evidence, so a single `make test` copied roughly **210 GB**. The tracked content
is 646 KB.

Nothing about the checks required the extra bytes: the validator reads prompt
files, tracked root structure, `scripts/*.sh`, and `git ls-files`. The untracked
tree was included because `tar -cf - .` is the shortest thing to write.

## The fix

```
git ls-files -z | tar --null -T - --ignore-failed-read -cf -
```

`--ignore-failed-read` covers a path that is tracked but absent locally, so a
deleted-but-not-committed file cannot abort a fixture build.
