# Release v2026-10-23.1 — evidence

Impact: additive

## What changed

`TASK-FILES` accepts a `host` operation, and `TASK-DESCRIPTION` an
`- Host: \`host[:resource]\`` line. A task that changes live host state and no
repository file can now declare its scope truthfully.

## Why

Adopting `00-homelab` reached a task that creates an LVM volume on two hosts and
touches no file in the repository. Its `TASK-FILES` said exactly that:

> No repository files are created or modified by this task.

The validator rejected it, because check 4 requires at least one
`| operation | \`path\` |` row and one `- <Verb>: \`path\`` line. The task had
three ways to pass and all of them were dishonest: invent a file operation,
declare an `inspect` of something it does not read, or drop the task.

`prompts/02-workflow.md` §7.1 already anticipates this shape — "skip this step
when the task changed no files" — so the workflow and the schema disagreed. This
is the third time a real task could not be expressed: the first two were
`rules.lock` as a root file (`2026-10-22.3`) and project-specific features
(`2026-10-22.4`).

## The addition

```
| host | `athena.lan:/datasets` |
| host | `beast.lan:/datasets` |
```

with matching `- Host: \`athena.lan:/datasets\`` lines. The token names the host and,
where it matters, the resource on it. A `host` operation authorizes no repository
edit, so such a task commits nothing under §7.1.

It cannot be used to smuggle a file operation: the row and operation line must
still agree, and any file the task edits needs its own `create`, `modify`,
`delete`, or `rename` row.

## Machine-checkable evidence

- `09-prompt-contract` accepts the operation list including `host`; an unknown
  operation still fails, and the corpus case that tests it is unchanged.
- `00-homelab`: task `02-datasets-volume-create` now conforms with two `host`
  rows and no invented file edit.
- Library suite: 9 tests; corpus: 54 rejected, 6 accepted.

## Behavioral evidence

Not applicable: the change adds a way to declare scope, and an agent still
cannot act on anything undeclared.
