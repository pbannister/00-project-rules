# Release v2026-10-22.10 — evidence

Impact: wording

## What changed

Two illustrative examples in shared documents, and two categories in the
conformance reporter. No rule changed.

## Why

`00-llm-integration` was adopted as the next project. Before touching it, the
pre-flight reported an unresolved reference in files it does not own:

```
prompts/how-to-write-tasks.md: reference does not exist: prompts/features/01-site-build.md
prompts/episodes/01-episode-template.md: reference does not exist: prompts/features/01-site-build.md
```

Both are `prompts/` paths, so the validator resolves them — correctly. But
`01-site-build.md` is a *skeleton* feature, and the shared documents were using it
as an example. Any project that does not carry that feature therefore failed on
two locked files it could not edit. The defect was invisible in the skeleton,
elseon and the canary because all three happen to have it.

This is the third instance of one pattern: **a shared artifact assuming the
template's inventory.** The eval cases assume `scripts/status.sh`; the episode
workflow assumed the project; this assumed a feature file. The rule for shared
material is that an example must not be a live reference.

## The second finding

The pre-flight also produced 17 findings the reporter could not classify, all
labelled "other":

- four features with no `## Purpose`, `## Requirements`, `## Behavior` or
  `## Dependencies` at all;
- two features numbered `02`.

Both are ordinary conformance work with an obvious action, so `rules-conform` now
recognises them as `feature format` and `numbering`. The "other" bucket exists for
a finding no hint covers; it should be rare, and it was not.

## Machine-checkable evidence

- Library suite: 8 tests, including the skeleton integration test that vendors
  this version into a copy of the template and runs the project validator there.
- `00-llm-integration` check 2 now reports no unresolved reference from the
  shared files.
- The two new categories are exercised by the same project: four `feature format`
  findings in four files, one `numbering` finding.

## Behavioral evidence

Not applicable: no instruction an agent follows changed. A wording release,
adoptable without an eval run.
